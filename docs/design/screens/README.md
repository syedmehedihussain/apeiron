# Design artboards

Exported from the Claude Design canvas (made while the app was called "Harness").
Open any `.dc.html` in a browser to see layout and styles. They load a `support.js` runtime that
is not included, so loops (`<sc-for>`) and `{{holes}}` will not fill in — read the markup and the
`renderVals()` sample data at the bottom of each file. `canvas.json` lists each artboard's title.

Live canvas: https://claude.ai/code/artifact/cf5ced28-473e-4402-a201-ffe30ff442bc
