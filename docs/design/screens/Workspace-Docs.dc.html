Overview

Core is a local personal dashboard. It runs on this computer at 127.0.0.1 and nothing else on the network can reach it. One Next.js app serves the pages and the API. All data lives in one SQLite file.

How a page loads

browser
  → app/page.tsx            // server component
  → lib/services/*          // plain functions, no cache
  → core.db (SQLite)

Rules

  • No background jobs. Everything is worked out when a page loads. ADR-0003
  • The server binds to loopback only. ADR-0002
  • Services never import from app/.
